# Halden Coffee Roasters — sample website

A single-page reference site for a coffee roaster and café, built as a sales sample. Halden is a fictional brand.

- Glass top bar that becomes a floating pill on scroll, with a sliding hover indicator, a photo mega menu and a full-screen phone menu
- Pinned farm-to-cup scroll story
- Draggable coffee shelf with momentum and spring snapping, product drawer and bag
- Roast dial you can turn or flick
- Café hours, subscription planner, footer

Plain HTML, CSS and JavaScript — no build step. Open `index.html` or serve the folder.
